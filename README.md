# 我们的地图

贾林峰 & 王悦淇。一张中国地图，点省份放大，点城市看那一年那一天的照片和话。
西安有单独的街道图，回忆钉在街上。

**不需要安装任何东西，不需要联网。双击 `index.html` 就能打开。**

---

## 现在的样子

- 3 个省：陕西、浙江、广东
- 6 座城市：西安、杭州、南浔、乌镇、珠海、汕尾
- 33 段回忆，60 张照片，从 2024-12-28 到 2026-10-05
- 首页显示「相伴 N 天」，每天自动 +1

## 改内容：只动 `data/memories.js`

每条回忆：

```js
{
  date: "2026-10-05",        // 排序用
  place: "海边",              // 显示在地点和地图钉上
  coord: [115.50, 22.70],    // 可选。有它才会在西安街道图上出现钉子
  title: "长隆",
  text: "你指着买海鲜的水缸说：你终于到珠海长隆啦。",
  photos: ["photos/shanwei/01.jpg", "photos/shanwei/02.jpg"]
}
```

- `coord` 只有西安用得上（西安是街道图）。写 `[经度, 纬度]`。
- 照片路径是相对 `index.html` 的，建议 **4:3，长边 1600px 左右，单张 500KB 以内**。
- 加新城市：在对应省份的 `cities` 里加一个键，写 `coord` 和 `items`。
- 加新省份：照着 `"陕西"` 的样子写 `note` + `cities`。

## 西安的街道图

`assets/xian.js` 里是手绘的骨架：明城墙、钟楼十字、二环三环、地铁 1/2/3/4 号线、护城河、几条主轴。
没有联网查真实路网（Overpass 从这边连不上），所以它是**示意图**，位置对到街区级，不是门牌号级。

想调：改里面的 `[经度, 纬度]` 就行，也可以加路：

```js
roads: [
  { name: "某条路", pts: [[108.94, 34.26], [108.95, 34.27]] }
]
```

## 操作

| 操作 | 效果 |
|---|---|
| 点省份 | 镜头推近，右侧换成这个省 |
| 点城市圆点 | 再推近；西安会换成街道图 |
| 点西安街上的小圈 | 右边滚动到对应的那段回忆 |
| 点空白 / `Esc` | 返回上一层 |
| 点照片 | 全屏看，`←` `→` 翻，`Esc` 关 |

**手机上**：地图铺满，底部卡片。全国时只露卡片顶部，点「目录」展开全部。
